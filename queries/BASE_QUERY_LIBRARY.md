# Base Query Library

The Version 1 manual contains the broad industry query bank. This file contains the execution format. Store each query with query_id, parent_id, sector, geography, language, source_class, mutation_type, query_text, created_at, result_count, qualified_yield, duplicate_rate, saturation_score, and status.

Initial query families:

- broad sector plus founder role
- process plus managing director
- product plus factory plus geography
- association plus office bearer
- conference plus speaker
- government database plus entity
- patent assignee plus founder
- industrial cluster plus company
- supplier/customer/competitor pivot
- public contact plus company

The Query Engine may add, mutate, retire, or reopen queries only through logged events.

# Execution Gates

## Discovery gate

Identity signal, relevance signal, reproducible path, no duplicate key.

## Verification gate

Two identity/company sources, primary business source, two operating signals, currentness check, claim ledger.

## Contact gate

Public source, exact value, professional purpose, directness, freshness, inferred=false.

## Scoring gate

All dimensions scored, rationales for extremes, confidence total, model version, critique complete.

## Portfolio gate

Category tolerance, diversity, hidden-gem and physical-operation constraints, no blocking candidate.

## Release gate

Schemas valid, claim lineage valid, zero blocking defects, exports complete, resume test passed.
